# 역할을 받은 에이전트의 시작점

1. 이번 역할과 지정 데이터 경로를 외부 오케스트라에서 확인합니다.
2. README, SECURITY, contracts를 읽습니다. 역할 이름 자체는 새 접근 권한이 아닙니다.
3. 코드 commit과 로컬 경로 binding을 확인합니다. 이 문서에 개인 경로·키를 넣지 않습니다.
4. 실제 CLI --help를 확인하고 stdin JSON으로 호출합니다.
5. 저장·수정은 실제 receipt와 재조회, 보고서는 집계값과 파일 내용을 확인합니다.
6. 성공/불완전/미확정·필요한 사용자 확인을 구분해서 보고합니다.

| 역할 | 허용 범위 |
| --- | --- |
| 로컬 기록 담당 | 지정 개인 원장의 원문 보존·보완·기간 통계 |
| 일반 사전 조사 담당 | 공개 영양정보 사전만, 개인 원장 조회 금지 |
| 보고 담당 | 승인된 보고서와 본인 수신처만 |
| 개발 담당 | 코드와 기술적 시험, 실제 개인 데이터 조회 금지 |

음식·양·단위가 불명확하면 확인하거나 미확정으로 남깁니다.
이미 있는 사전 정보를 먼저 조회하고 새 항목만 공개 원문으로 조사합니다.
일반 사전과 개인 식사·체중·별칭·빈도를 합치지 않습니다.
OCR와 웹 조사는 외부 도구가 공급하며 모델 응답만으로 저장 완료를 주장하지 않습니다.
